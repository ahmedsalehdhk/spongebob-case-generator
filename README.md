# 🧽 sPoNgEbOb TeXt GeNeRaToR

Generate mOcKiNg sPoNgEbOb case text instantly in your browser! This project provides a fun and interactive tool for converting regular text into SpOnGeBoB cAsE, inspired by the famous SpongeBob meme.


Key Features

- Real-time Transformation: Instant text-to-meme conversion using an alternating-case algorithm.
- Next.js 15 Architecture: Leverages the latest App Router and React Compiler for optimized performance.
- Neo-Brutalist UI: A bold, high-contrast interface built with Tailwind CSS.
- One-Click Copy: Seamless clipboard integration for quick sharing.

Tech Stack:

- Framework: Next.js 15 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Deployment: Vercel
